# Relay — Clean Technical (design canvas export)

Source files of the Relay design canvas.

- Main.dc.html — Home (AI operations workspace)
- AgentWorkspace.dc.html — Agent workspace: chat, details sidebar (gear), activity panel
- WorkspaceSettings.dc.html — Settings
- Foundations.dc.html — Clean Technical tokens and components
- Sidebar.dc.html — shared sidebar component
- AgentIcon.dc.html — shared agent character icon
- canvas.json — canvas layout index

These are Design Component (.dc.html) files. They render inside the Claude design canvas
(they load its runtime via support.js), so open them there. For PNG or PDF, use
Share › Export in the canvas.
